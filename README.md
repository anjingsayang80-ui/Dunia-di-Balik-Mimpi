# Dunia di Balik Mimpi

Buku cerita bergambar bergaya anime 2D berwarna, ditulis dalam bahasa Indonesia.

## Membaca buku
Buka `index.html` melalui GitHub Pages atau jalankan situs secara lokal. Gunakan tombol **Sebelumnya** dan **Berikutnya** untuk berpindah halaman. Setiap halaman menampilkan ilustrasi komik dan dialog antar tokoh dalam balon percakapan.

## Menjalankan GitHub Pages
1. Buka **Settings** pada repository.
2. Pilih **Pages**.
3. Pada **Build and deployment**, pilih **Deploy from a branch**.
4. Pilih branch **main** dan folder **/ (root)**, lalu tekan **Save**.

## Kemajuan cerita
- Sampul: tersedia.
- Halaman cerita 1–16: tersedia.
- Halaman 7–11 menambahkan kemunculan Pemburu Mimpi, peta bercahaya, pertemuan dengan Ren, dan perjalanan melewati gerbang pertama.
- Halaman 12–16: memasuki Hutan Seribu Bisikan, menghadapi suara peniru dan Penjaga Akar, serta mengungkap segel misterius Ren.
- Halaman 17–200: akan dilanjutkan secara bertahap.
- Ilustrasi halaman tersimpan sebagai SVG orisinal di folder `assets/`.

## Tokoh utama
Arka, Rina, Ren, dan Kuro.
