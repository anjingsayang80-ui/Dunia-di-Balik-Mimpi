# Dunia di Balik Mimpi

Buku cerita bergambar anime berbahasa Indonesia.

## Membaca
Buka halaman GitHub Pages setelah diaktifkan.

## Menjalankan GitHub Pages
1. Buka **Settings** pada repository.
2. Pilih **Pages**.
3. Pada **Build and deployment**, pilih **Deploy from a branch**.
4. Pilih branch **main** dan folder **/ (root)**, lalu tekan **Save**.

## Status
- Sampul: tersedia.
- Halaman 1: tersedia.
- Halaman 2–200: direncanakan dan akan diterbitkan bertahap.
