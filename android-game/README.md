# Dunia di Balik Mimpi — Anime RPG 3D (Godot)

Prototipe game RPG 3D offline untuk Android. Proyek ini ditambahkan di folder `android-game/` agar tidak mengubah buku komik yang sudah ada di root repository.

## Membuka proyek
1. Instal Godot 4.x.
2. Import `android-game/project.godot` melalui Godot Project Manager.
3. Tekan Play untuk menjalankan prototipe.

## Kontrol
- PC: WASD / tombol panah untuk bergerak, Space untuk menyerang.
- Android: joystick layar kiri dan tombol SERANG.

## Build APK
APK belum dikompilasi. Untuk membuatnya, pasang Android export templates Godot, konfigurasi Android SDK/JDK, lalu buka Project > Export, tambah preset Android, dan ekspor APK.

## Isi prototipe
- Arena 3D dengan pencahayaan dan dekorasi.
- Karakter pemain, slime musuh, serangan jarak dekat, HP.
- HUD dan kontrol sentuh.

Model saat ini memakai bentuk geometri placeholder; aset karakter anime detail, animasi, suara, quest, dan progresi level masih perlu dikembangkan.
